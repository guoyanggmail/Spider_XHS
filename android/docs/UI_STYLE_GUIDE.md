# Android UI Style Guide

## 1. 视觉定位

- 风格方向：轻拟态借鉴小红书，不做 1:1 仿制。
- 页面目标：像内容型产品，不像后台管理工具。
- 视觉关键词：留白、轻卡片、暖白底、红色强调、弱边框、清晰层级。

## 2. 颜色规范

| 类型 | 说明 |
|---|---|
| 主色 | 红色系，用于主按钮、选中态、关键 CTA |
| 背景色 | 浅暖白，避免冷灰管理台质感 |
| 卡片色 | 纯白或浅暖粉底 |
| 文本主色 | 深灰，不用纯黑硬边 |
| 文本次色 | 中灰，用于说明和辅助信息 |
| 边框色 | 很浅的暖灰边框 |
| 状态色 | 成功用绿色，错误用红色，提醒用橙色 |

## 3. 字体层级

| 层级 | 用途 |
|---|---|
| `headlineLarge` | 登录页品牌标题 |
| `headlineSmall` | Tab 页标题 |
| `titleLarge` | 卡片主标题 |
| `titleMedium` | 区块标题、内容卡片标题 |
| `bodyLarge` | 页面说明 |
| `bodyMedium` | 正文、摘要 |
| `bodySmall` | 辅助信息、状态说明 |
| `labelLarge` | 按钮文案 |

规则：

- 不使用默认 Material 字距。
- 标题字重偏重，正文保持常规。
- 辅助文案必须明显弱于主标题。

## 4. 组件规范

### 按钮

- 主按钮：红底白字，大圆角。
- 次按钮：浅底、深字，不用深色实体按钮。
- 同一区域最多一个主按钮，其余用次按钮。

### 输入框

- 白底、浅边框、圆角。
- 聚焦态边框切到主红色。
- 表单区保持固定节奏，不堆太多密集控件。

### 卡片

- 使用小阴影和大圆角。
- 内边距统一。
- 页面信息按卡片分组，不做大面积描边面板。

### 底部 Tab

- 白底。
- 选中态使用主红色。
- 未选中态使用灰色。
- 保持轻量，不用厚重深色导航栏。

### 状态提示

- 用轻量提示条，不用大块调试面板。
- 加载态只显示一个小型 loading 指示。

## 5. 页面规范

### 登录页

- 顶部放品牌标题和一句简短说明。
- 主体先展示登录卡片。
- 后台地址设置作为次级卡片放在下方。

### 发帖页

- 先展示任务获取动作。
- 当前任务信息单独成卡。
- 结果回传区放在同一工作卡片中。

### 搜索页

- 搜索输入区放在第一卡片。
- 即时搜索结果优先于任务列表展示。
- 搜索结果卡片更像内容流，而不是表格。

### 我的页

- 顶部优先展示头像、昵称、轻标签和三列统计，弱化工具面板感。
- 内容区先展示笔记列表，布局更接近内容产品个人主页。
- 右上角进入独立设置页，不把语言、连接地址、退出登录直接堆在资料主页。

### 设置页

- 作为“我的”页的二级页面存在。
- 语言、连接地址、退出登录、账号校验统一收纳到设置页。
- 语言切换必须展示当前选中态。
- 设备信息放在最底部，作为弱化的只读信息区块。

## 6. 国际化规范

- 所有用户可见文案必须进入资源文件。
- 中文使用 `values/strings.xml`。
- 英文使用 `values-en/strings.xml`。
- 禁止在 Compose 中直接硬编码用户可见文本。
- 新增按钮、标题、提示、错误语句时必须同步补双语。

## 7. 后续约束

- 新页面默认复用现有 theme token 和按钮/卡片/输入框样式。
- 不允许重新回到默认 Material 紫色主题。
- 如果要增加新视觉元素，先更新本文件，再改实现。
