# Android 端需求

## 当前定位

Android 项目是小红书 App 自动化执行端。本项目负责调用后台接口、保存设备配置、承接任务、执行小红书 App 操作、回传结果。

Web 管理后台只负责任务和账号管理，不直接执行小红书发布、搜索和采集。

## 首期功能

| 模块 | 功能 | 状态 |
|---|---|---|
| 后台连接 | 配置后台 Base URL | 已纳入首期 |
| 设备注册 | 上报 `device_id`、`app_instance_id`、`app_version`、`device_name` | 已纳入首期 |
| 主号 Cookie | 手动录入或登录后同步主 Cookie 到后台 | 已纳入首期 |
| 任务拉取 | 调用 `GET /api/app/tasks/next` 获取一个任务 | 已纳入首期 |
| 结果回传 | 调用 `POST /api/app/tasks/{type}/{id}/result` 幂等回传 | 已纳入首期 |
| 发帖执行 | 打开小红书并发布图文/视频 | 后续接无障碍执行器 |
| 搜索采集 | 打开小红书搜索关键词并采集结果 | 后续接无障碍执行器 |
| 账号监控 | 采集个人页和帖子详情数据 | 后续接无障碍执行器 |

## 风控要求

1. App 每次只领取一个任务。
2. 后台返回无任务时不要高频轮询，默认 60 秒以上。
3. 发帖只能使用主号 Cookie。
4. 搜索和监控任务使用后台分配的小号 Cookie。
5. 任务失败必须回传错误信息，不在 App 本地无限重试。
6. Cookie 不在日志中明文输出。
