# Android 端需求

## 当前定位

Android 项目是小红书账号操作客户端。本项目负责手机号验证码登录、保存登录态、创建关键词搜索任务、查看搜索结果、拉取后台发帖任务、执行发布并回传结果。

Web 管理后台负责创建和审核发帖任务、查看任务和结果，不直接执行小红书发布、搜索和采集。

## 页面结构

1. 启动先判断是否已登录。
2. 未登录时进入登录页。
3. 登录成功后进入首页。
4. 首页底部固定三个 Tab：发帖、搜索、我的。
5. “我的”页面可查看账号详情并支持退出登录。
6. Android 全量用户可见文案支持中英文切换。
7. Android 视觉风格默认遵循 `UI_STYLE_GUIDE.md`。

## 首期功能

| 模块 | 功能 | 状态 |
|---|---|---|
| 接口地址 | 配置后台 Base URL | 已纳入首期 |
| 手机号登录 | 手机号 + 短信验证码登录并获取主账号 Cookie | 已纳入首期 |
| 主号 Cookie | 登录后本地保存，并同步后台账号状态 | 已纳入首期 |
| Cookie 状态校验 | 校验后台记录的主账号 Cookie 状态，失效后要求重新登录 | 已纳入首期 |
| 发帖任务拉取 | 调用 `GET /api/app/tasks/next` 获取后台创建的发帖任务 | 已纳入首期 |
| 结果回传 | 调用 `POST /api/app/tasks/{type}/{id}/result` 幂等回传 | 已纳入首期 |
| 即时搜索 | 直接执行关键词搜索并返回帖子列表和帖子详情字段，不依赖先创建任务 | 已纳入首期 |
| 关键词任务创建 | 调用 `POST /api/app/search-tasks` 创建搜索任务 | 已纳入首期 |
| 搜索任务查看 | 查看任务详情、帖子数量、帖子列表，点击帖子进入详情页查看正文、话题、图片、视频 | 已纳入首期 |
| 发帖执行 | 使用本地 Cookie 调接口发布图文/视频 | 后续接真实执行器 |
| 搜索采集 | 使用本地 Cookie 搜索关键词并采集结果 | 后续接真实执行器 |
| 账号信息 | 查看当前登录账号个人信息 | 后续接真实接口 |

## 风控要求

1. App 每次只领取一个任务。
2. 后台返回无任务时不要高频轮询，默认 60 秒以上。
3. 发帖、关键词搜索和账号信息查看都必须复用本地登录 Cookie，不重复登录。
4. 同一账号的小红书业务请求必须串行限速。
5. 任务失败必须回传错误信息，不在 App 本地无限重试。
6. Cookie 不在日志中明文输出。
7. Cookie 状态失效后，App 必须清空本地登录态并阻止继续领取或执行任务，直到重新登录。
