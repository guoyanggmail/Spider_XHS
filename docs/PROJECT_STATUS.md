# 项目状态

最后更新：2026-05-08

## 现状说明

- 业务方向已调整为“App 执行 + Web 管理”。
- 当前仓库代码仍保留一部分历史 Web 直接执行能力。
- 文档已先按新方向更新，后续代码需要逐步和文档对齐。
- 最新边界：后台创建发帖任务；App 创建关键词搜索任务、查看搜索任务详情和帖子数据；App 使用本地登录态执行发帖、搜索和账号信息查询。

## 已完成

- 创建 Web 管理后台基础架构。
- FastAPI 本地后端。
- Vite + React + TypeScript 前端。
- Tailwind CSS + shadcn/ui 配置体系。
- 多账号 Cookie 管理基础能力。
- 账号管理支持 Cookie 保存、脱敏展示和有效性校验。
- 账号级请求限速、失败冷却、Cookie 短期校验缓存。
- 发帖任务、搜索监控、结果保存、账号分析快照等基础数据模型。
- 关键词搜索摘要和按需详情加载能力。
- 运营概览页。
- Docker 单容器部署。
- Docker Compose 一键启动。
- 页面中英文切换入口。
- 第一版自动化测试体系：pytest 后端 API 测试、前端构建检查、一键检查脚本。

## 待按新方向改造

- 将 Web 页面从“直接执行业务”调整为“只做管理系统”。
- 将发帖能力改为 App 拉任务、App 回结果。
- 将关键词采集改为 App 拉任务、App 回传采集结果。
- 将账号数据监控改为 App 采集后回传快照。
- 增加主账号 Cookie 与小号 Cookie 池的分层管理。
- 增加小号 Cookie 轮询分配、冷却、停用和恢复机制。
- 增加 App 登录后上传主 Cookie 的接口。
- 增加待发帖列表、已发帖列表、采集任务列表、采集结果列表的管理视图。
- 增加 App 创建关键词搜索任务接口。
- 增加 App 查看关键词任务详情、帖子数量和帖子列表接口。
- 增加 App 手机号验证码登录接口。
- Android 页面已按设置、账号、搜索、发帖四个模块拆分，账号模块已接通验证码登录调用链。

## 当前优先级

- 主 Cookie 与小号 Cookie 池设计。
- 发帖任务接口改造。
- 搜索采集任务接口改造：以 App 创建和查看为主。
- 博主与账号数据监控接口改造。
- 管理后台页面重构。
- 测试改造，避免继续围绕历史“Web 直接发帖”路径扩展。

## 暂缓或不再作为当前主线

- 私信监控。
- 私信自动回复。
- 评论自动回复。
- Web 端直接发帖作为核心方案。
- Web 端直接执行搜索采集作为核心方案。

## 每次开发后的更新要求

每次新增或修改功能后，至少更新以下内容：

- `docs/PROJECT_STATUS.md`：补充已完成任务和计划变化。
- `docs/REQUIREMENTS.md`：需求范围变化时更新。
- `docs/DEPLOYMENT.md`：部署方式、端口、环境变量变化时更新。
- `docs/NOTES.md`：新增注意事项、风险或约束时更新。
- `docs/TESTING.md`：测试命令、覆盖范围、约定变化时更新。
- `RISK_CONTROL.md`：风控策略变化时更新。
